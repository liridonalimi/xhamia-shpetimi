# Moduli 01 · Website publik dhe identiteti vizual

Qëllimi: të kthehet koncepti i fundit në website funksional, responsive, në shqip dhe gjermanisht.

Përfshin identitetin SVG, ballinën, orarin e papublikuar, faqet e bashkësisë dhe kontaktit, mbështetjen dhe draftet ligjore. Nuk përfshin administrim, pagesa, njoftime të sajuara ose orare të llogaritura pa miratim.

Kriteret: rrugët funksionojnë, ndërrimi i gjuhës ruan faqen, kontaktet janë të sakta, nuk ka overflow në telefon, menuja kontrollohet me tastierë dhe asnjë orar shembull nuk shfaqet si orar real.

Statusi i validimit regjistrohet në dokumentimin teknik.
